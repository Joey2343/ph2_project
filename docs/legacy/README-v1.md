# ระบบศูนย์กลางการบริหารจัดการ สพป.แพร่ เขต 2

ระบบเว็บสำหรับบริหารจัดการภายในสำนักงานเขตพื้นที่การศึกษาประถมศึกษาแพร่ เขต 2
(หน้าแรกเป็นเมนูไอคอน มีระบบสมาชิก และระบบหลังบ้านสำหรับผู้ดูแลระบบ)

## วิธีเริ่มใช้งาน

### บน Windows
1. เปิดไฟล์ `start.bat` (ดับเบิลคลิก)
2. เปิดเบราว์เซอร์แล้วเข้าไปที่: **http://localhost:3000**

### บน macOS / Linux
```bash
./start.sh
```

> หมายเหตุ: โปรเจกต์นี้ใช้ Node.js แบบพกพา (โฟลเดอร์ `runtime/`) ที่รวมมาด้วยแล้ว
> ถ้าไม่มีโฟลเดอร์ `runtime/` ให้ติดตั้ง Node.js LTS (https://nodejs.org) ก่อน แล้วรัน `npm install && npm start`

## เมนูของระบบ

1. **ข้อมูลพื้นฐาน สพป.แพร่ เขต 2** — ประวัติ วิสัยทัศน์ โครงสร้าง การติดต่อ *(เปิดให้ดูทั่วไป)*
2. **พิกัดโรงเรียนในสังกัด** — แผนที่และข้อมูลโรงเรียน *(เปิดให้ดูทั่วไป)*
3. **ลงเวลาทำงาน** — ลงเวลาเข้างาน-ออกงาน
4. **จองยานพาหนะ** — ขอใช้ยานพาหนะ (รออนุมัติ)
5. **จองห้องประชุม** — จองห้องประชุม (รออนุมัติ)
6. **บันทึกข้อความ** — จัดทำและส่งบันทึกข้อความพร้อมไฟล์แนบ
7. **ขออนุญาตไปราชการ** — ยื่นคำขอเดินทางไปราชการ (รออนุมัติ)
8. **ขออนุญาตลา** — ยื่นคำขอลาประเภทต่าง ๆ (รออนุมัติ)
9. **หนังสือราชการ** — ทะเบียนหนังสือรับ-ส่ง พร้อมไฟล์แนบ
10. **บริหารงบประมาณ** — แผนงบประมาณ รายรับ-รายจ่าย คงเหลือ
11. **บริหารงานวิชาการ** — โครงการ/กิจกรรมทางวิชาการ
12. **เจ้าหน้าที่ในระบบ** — จัดการสมาชิก อนุมัติการสมัคร *(ผู้ดูแลระบบเท่านั้น)*

## ระบบสมาชิก

- **ผู้ที่ยังไม่เป็นสมาชิก** เปิดดูได้เฉพาะเมนู 1 และ 2 พร้อมปุ่ม เข้าสู่ระบบ / ลงทะเบียน
- **การลงทะเบียน** กรอกข้อมูลส่วนตัว (อ้างอิงเลขบัตรประชาชน 13 หลัก พร้อมตรวจสอบความถูกต้อง),
  ชื่อผู้ใช้/รหัสผ่าน, รูปถ่าย และลายเซ็น (วาดหรืออัปโหลด) แล้วรอผู้ดูแลระบบอนุมัติ
- **หลังอนุมัติ** สมาชิกสามารถเข้าสู่ระบบและใช้เมนู 3–11 ได้ทั้งหมด

## โครงสร้างโปรเจกต์

```
server.js            — เซิร์ฟเวอร์หลัก (Express)
db.js                — ฐานข้อมูล SQLite + ข้อมูลตัวอย่าง
lib/                 — auth (session, รหัสผ่าน, เลขบัตรประชาชน) และ uploads
routes/              — API แต่ละกลุ่มงาน
public/              — ส่วนหน้าเว็บ (HTML/CSS/JS ไม่มี build)
public/uploads/      — ไฟล์ที่อัปโหลด (รูป, ลายเซ็น, เอกสาร)
data.db              — ฐานข้อมูล (สร้างอัตโนมัติครั้งแรกที่รัน)
```

## ข้อมูลตัวอย่าง

ระบบจะสร้างข้อมูลตัวอย่าง (โรงเรียน ยานพาหนะ ห้องประชุม งบประมาณ โครงการวิชาการ)
ให้ครั้งแรกที่รัน ผู้ดูแลระบบสามารถแก้ไข/ลบได้ตามข้อมูลจริงของหน่วยงาน
